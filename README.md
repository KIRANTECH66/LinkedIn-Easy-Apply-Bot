Complete agent responsibility matrix
Agent

Main responsibility

Expected output

1. Profile Agent

Extracts and verifies candidate information and preferences

Structured candidate profile

2. Job Discovery Agent

Finds relevant job postings from authorized sources

Normalized job records

3. Job Matching Agent

Evaluates candidate-job compatibility and eligibility

Match score, strengths, gaps

4. Resume Agent

Tailors the resume to a specific job description

Tailored resume version

5. Senior Technical Recruiter Agent

Evaluates resume and JD from a recruiter screening perspective

Screening score, concerns, feedback

6. Hiring Manager Persona Agent

Evaluates evidence of technical depth, ownership, and business impact

Role-fit score, technical gaps

7. ATS Evaluation Agent

Checks parsing, terminology, section structure, and relevant keywords

ATS-readiness score and missing terms

8. Application Agent

Opens supported application workflows and fills standard fields

Completed application draft

9. Question Agent

Answers application questions using verified candidate facts

Proposed answers with evidence

10. Approval Agent

Presents the final application package for candidate review

Approved or rejected application state

11. Tracking Agent

Tracks status, interview stages, outcomes, and follow-ups

Application history and dashboard
